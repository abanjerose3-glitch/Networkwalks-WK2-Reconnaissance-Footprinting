# Networkwalks — Week 2 Reconnaissance & Footprinting

Cybersecurity internship laboratory work focused on reconnaissance,
information gathering, and network discovery using Kali Linux and
authorized security assessment tools.

## Overview

This repository documents my Week 2 cybersecurity internship activities
at Networkwalks, including reconnaissance, footprinting, and network
